# Branding & Visual Identity

Clip Squeezer uses a cohesive, light-touch visual identity designed for readability, clarity, and simplicity.

## Resources

- [Visual Brand Gallery](../branding/index.html) (open offline in any browser)
- [Usage Guide and Asset Inventory](../branding/README.md)

## Core Assets

- **Logos**: Horizontal, stacked, and reversed variants in `branding/logos/`.
- **App Icons**: Standard multi-resolution desktop icons (`.ico`, `.icns`, `.png`) in `branding/app-icons/`.
- **Interface Glyphs**: 27 custom vector icons in `branding/icons/` for UI actions, playback, and navigation.
- **Social & Banners**: Open Graph card and repository banner in `branding/social/`.

All brand assets are original vector artwork licensed under the project dual MIT or Apache-2.0 license.
