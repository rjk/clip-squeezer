# Branding & Visual Identity

Clip Squeezer uses a cohesive, light-touch visual identity designed for readability, clarity, and simplicity.

## Resources

- [Visual Brand Gallery](branding/index.html) (open offline in any browser)
- [Usage Guide and Asset Inventory](branding/README.md)

## Core Assets

- **Logos**: Horizontal, stacked, and reversed variants in `docs/branding/logos/`.
- **App Icons**: Standard multi-resolution desktop icons (`.ico`, `.icns`, `.png`) in `docs/branding/app-icons/`.
- **Interface Glyphs**: 27 custom vector icons in `docs/branding/icons/` for UI actions, playback, and navigation.
- **Social & Banners**: Open Graph card and repository banner in `docs/branding/social/`.
